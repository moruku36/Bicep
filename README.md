# Azure Bicep Practice

[English](README.md) | [日本語](README.ja.md)

Personal Azure infrastructure examples in Bicep, largely adapted from Microsoft Learn. Templates cover networking, AKS, App Service, databases, Front Door, and Key Vault.

## Use the examples

Choose the Bicep file for the Azure service you want to study and inspect its parameters and resources before deployment. These are learning examples largely copied or adapted from Microsoft Learn, rather than one integrated deployment.
